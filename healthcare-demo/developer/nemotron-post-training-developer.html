What the Evaluation Measures

The training sample is a complete stateful episode, not a single prompt-response pair. Reward is emitted only after the agent has conversed, called tools, and reached a terminal outcome.

Use-Case + GRPO Loop

01 Practice case Patient profile, scenario, task goal, and initialized clinic state.
02 NeMo Gym rollout The simulated patient and assistant run a repeatable multi-turn episode.
03 Assistant + tools Nemotron acts through scheduling, prescription, telehealth, and profile tools.
04 Behavior verifier Six clinician-grounded rubric axes become scores, rationales, and reward.
05 NeMo RL / GRPO Rollout-group rewards update the open policy toward verified behavior.
06 Nemotron checkpoint The improved policy returns to Gym for held-out re-evaluation.
Feedback loop Workflow evaluation measures the episode; NeMo RL uses GRPO to improve the policy; the next checkpoint is tested against the same clinical workflow bar.
